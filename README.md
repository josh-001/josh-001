## Hi there 👋
Hey there! I'm a curious and driven developer who loves exploring the intersection of **AI Agents**, **Cloud Infrastructure**, and **Robotics**.

I work with **Python** for everything from machine learning and deep learning to backend development. I build **agentic AI architectures** on **AWS Bedrock**, engineer **serverless backends** with Lambda, API Gateway, and Step Functions, and have hands-on experience with **ROS/ROS2** for robotic systems. I enjoy solving real-world problems — from autonomous warehouse robots to healthcare claim automation.

Check out some of my work, like my **Human Activity Recognition System** using deep learning, or my **Sentinel-1 Land Classification** project using OpenCV and ML.
